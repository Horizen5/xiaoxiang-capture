# 部署与排错

## 一、环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| 系统 | Windows 10 / 11 x64 | 依赖 Win32 API（窗口枚举、SendInput、PrintWindow） |
| Python | 3.10+ | 只用标准库 + `websockets` |
| Node.js | 18+ | 跑 `wmpfdebugger`（TypeScript，用 tsx 直接执行） |
| 微信 | PC 版 4.x，已登录 | 当前适配 4.1.15.56 |
| 小程序 | 小象超市（`wx92916b3adca84096`） | 能在微信里正常打开 |

## 二、安装

```bat
cd tools
pip install -r requirements.txt

cd wmpfdebugger
npm install
cd ..\..
```

`wmpfdebugger` 是第三方开源项目（作者 evi0s，GPL-2.0），源码已随包提供。
`npm install` 会拉 `frida`（约 50MB）和 `tsx`。

## 三、启动

双击 `start beta.bat`。

它会依次：检查小程序进程 → 起调试代理(62000) → 起看板(8899) → 起抓包 →
进入守护循环。**这个黑窗口必须一直开着**，关掉等于全部停止。

### 正确的操作顺序

1. 微信里把「小象超市」**完全关掉**（右上角 ×，不是退到上一页）
2. 双击 `start beta.bat`，等到出现「调试代理已就绪」
3. 打开小程序 → 进「分类」页
4. 浏览器开 `http://127.0.0.1:8899/`
5. 手动上下滑，看板数字实时涨

> 顺序不能反。CDP 连接是小程序**进程启动时**建立的，脚本先跑、小程序后开才接管得到。

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 「找不到 node.exe，调试代理起不来」 | PATH 里没有 node | 装 Node.js；启动器会自动扫常见位置（`.workbuddy/binaries/node`、`Program Files\nodejs`、nvm、scoop） |
| 「已经有一个 beta 在运行（pid xxxx）」 | 真的有一份在跑，或 pid 被复用（已修复） | 看任务管理器有没有 python 在跑；新版会打印「清掉了一条过期的运行记录」并继续启动 |
| 代理在等小程序，但小程序还没连上来 | 小程序开得比脚本早 | 把小程序整个关掉再开一次 |
| 看板一片空白 | `live_raw/` 里没数据 | 确认抓包进程活着：看 `tools/live_stdout.log` |
| 数字一直是「x-y」黄色 | 该分类没翻到底 | 继续往下滑；接口翻到底会自动变正常 |
| 弹了滑块验证 | 翻页太快，或调试通道改变了环境 | 见下节 |
| 图片有缺 | 图片是异步下载的 | 等一会儿刷新看板；或跑 `python tools\make_image_index.py` 看缺哪些 |

## 五、被风控了怎么办

抓包侧**只记录**不主动发请求时几乎不会触发。真触发了按顺序排查：

1. **先把自动模式关掉**（看板顶部切成「手动」），只手动翻页观察
2. 彻底退出微信：任务管理器确认没有 `Weixin.exe`、`WeChatAppEx.exe`
   —— 注入的 `RemoteDebugMode` 是**进程级**开关，不重启微信不会复位
3. 重新登录微信，先不用脚本，纯手动翻几页，看是否还弹验证
4. 手动正常后再启动脚本；仍弹 → 说明是调试通道本身触发的，那就只能不注入（项目不覆盖这种模式）

## 六、想彻底停干净

```bat
:: 1. 关掉启动器窗口（Ctrl+C 或直接关）
:: 2. 确认没有残留
tasklist | findstr /i "python node"
:: 3. 有残留就按 pid 结束
taskkill /PID <pid> /F
```

正常情况下启动器按 Ctrl+C 会带走所有子进程。pid 文件留在 `tools/` 里也没关系——
下次启动会做身份校验，对不上就自动清掉。

## 七、换一台机器要改什么

| 改什么 | 在哪 |
|---|---|
| 搜索关键词 | `tools/_launch.json` 的 `search` 字段（默认 `xxcs`） |
| 端口 | `start_beta.py` 顶部 `PROXY_PORT` / `BOARD_PORT` |
| 小程序 appid | `start_beta.py` / `live_capture.py` 的 `APP_HINT` |
| 自定义启动命令 | `tools/_launch.json` 的 `cmd`，例如 `{"cmd": "start \"\" \"C:\\...\\小象超市.lnk\""}` |
